6.1 Project files and data access

The report is organised as a Quarto book. The chapter source files, _quarto.yml, references.bib, the data and figures folders, and renv.lock should be kept together in the Final Report project folder. All R chapters use relative paths so that the project can be moved across machines without relying on machine-specific directory paths.

The group shares the project through its GitHub repository. The Final Report/data folder is the central location for all report inputs and intermediate artefacts. For exact reproduction, retain the repository copy or commit identifier used for rendering.

The following files in Final Report/data are used by the R chapters across Tasks 1, 2, and 3:

File Use in the report
data/gse159717_rnaseq_deseq_5dpi_counts_raw.tsv Input RNA-seq count matrix for the Task 1 differential expression analysis.
data/consensus_table.rds Generated by Task 1 and read by Task 2 to carry forward the consensus differentially expressed genes.
data/chr12_OAS2_7samples.vcf Subset of the IGSR GRCh38 chromosome 12 phased VCF covering the OAS2 target region for the seven study individuals.
data/sampled_chr1.vcf.zip Course-provided GRCh38 chromosome 1 VCF subset for the seven individuals, read directly in R for the off-target overlap scan.
data/sampled_chr2.vcf.zip Course-provided GRCh38 chromosome 2 VCF subset for the seven individuals, read directly in R for the off-target overlap scan.
data/offtargetsguide.txt CRISPOR off-target export from Task 2 used to screen chromosome 1 and 2 off-target intervals in Task 3.

Provenance of the VCF datasets

  • Chromosomes 1 and 2 (sampled_chr1.vcf.zip, sampled_chr2.vcf.zip): Pre-filtered 1000 Genomes Project subsets provided by the teaching team containing polymorphic variant calls on chromosomes 1 and 2 for seven individuals (HG00142, HG00178, HG00237, HG01521, HG03129, NA19175, and NA19462).
  • Chromosome 12 (chr12_OAS2_7samples.vcf): Extracted from the official IGSR GRCh38 phased release (ALL.chr12.shapeit2_integrated_snvindels_v2a_27022019.GRCh38.phased.vcf.gz) for the OAS2 exon 1 region (12:112978600-112978850) and subsetted to the same seven sample IDs:
bcftools view \
  -r 12:112978600-112978850 \
  -s HG00142,HG00178,HG00237,HG01521,HG03129,NA19175,NA19462 \
  https://ftp.1000genomes.ebi.ac.uk/vol1/ftp/data_collections/1000_genomes_project/release/20190312_biallelic_SNV_and_INDEL/ALL.chr12.shapeit2_integrated_snvindels_v2a_27022019.GRCh38.phased.vcf.gz \
  -Ov -o chr12_OAS2_7samples.vcf

During R rendering in Task3.qmd, any population-only records where all seven individuals are homozygous for the reference allele (0|0) are filtered out so that the chromosome 12 subset matches the filtering convention of the chromosome 1 and 2 files.

6.2 Accessing the analysis code

All data processing, statistical modelling, VCF parsing, sequence comparisons, and visualisations are executed in R and embedded within the HTML chapters for Tasks 1, 2, and 3. Open the relevant chapter and click Code in the top-right corner of the page.

6.3 Reproduction workflow

To reproduce the complete report from scratch:

  1. Clone or download the project repository and retain its folder structure.
  2. Open Final Report.Rproj in RStudio in a fresh R session.
  3. Restore the recorded R package environment from renv.lock by running renv::restore().
  4. Render the Quarto book to HTML via the RStudio Render Book button or by running quarto render in the terminal from the Final Report directory.

The three analytical stages execute in sequence during rendering:

  1. Task 1 (Task1.qmd): Reads data/gse159717_rnaseq_deseq_5dpi_counts_raw.tsv, performs the differential expression analyses (DESeq2 and edgeR), and exports the consensus gene table to data/consensus_table.rds.
  2. Task 2 (Task2.qmd): Reads data/consensus_table.rds, justifies the selection of OAS2, extracts the first-exon target region, and evaluates candidate CRISPRi guides (200forw and 248forw) using CRISPOR predictions.
  3. Task 3 (Task3.qmd): Reads data/chr12_OAS2_7samples.vcf to verify on-target guide and PAM conservation across the seven individuals on chromosome 12, and screens data/sampled_chr1.vcf.zip and data/sampled_chr2.vcf.zip against the CRISPOR off-target intervals (data/offtargetsguide.txt / snapshots) to evaluate haplotype-specific off-target binding risk in R.
