4.1 Objective

In Task 2, two CRISPR interference (CRISPRi) guides, 200forw and 248forw, were selected for the first exon of OAS2 using CRISPOR predictions (Haeussler et al. 2016). Human genetic variation may change an intended target or a predicted off-target site. Task 3 asks whether each genome still contains a matching target and PAM, and whether off-target recognition changes. The chromosome 1/2 analysis checks predicted off-target sites. A separate chromosome 12 analysis checks both intended OAS2 targets in the same seven individuals.

4.2 Approach

The CRISPOR off-target prediction table generated in Task 2 was originally imported into a Python Jupyter Notebook and filtered to include only the selected OAS2 guides (200forw and 248forw). Predicted off-target coordinates, guide sequences, mismatch counts and off-target scores were extracted for further analysis. Reusing these predictions provided a direct way to refine the guide selection from Task 2, while keeping the same candidate guides.

Variant information came from the chromosome 1 and chromosome 2 VCF files used in the original analysis. They contain genotypes for HG00142, HG00178, HG00237, HG01521, HG03129, NA19175 and NA19462. A VCF records the reference and alternate alleles, positions and individual genotypes (Danecek et al. 2011). Variant positions were compared with reference-predicted off-target intervals on these two chromosomes. The full recognition region includes the protospacer and PAM, since a variant in either may matter. Predicted off-target sites on other chromosomes and new variant-created sites were not searched.

For the single overlapping SNP, the original notebook recorded the reference and alternate off-target sequences. This R analysis separates each 23-base sequence into the 20-base protospacer matched by the guide and the 3-base PAM. Mismatches are counted only in the protospacer. This follows the target structure discussed in Lecture 6: a 20-base sequence next to a canonical NGG PAM. Mismatch position and type also matter, so the count alone cannot quantify off-target activity (Haeussler et al. 2016).

The genotype was used to distinguish reference homozygotes, heterozygotes and alternate homozygotes. In the VCF, 0 denotes the reference allele, 1 the first alternate allele, and | indicates phased alleles (Danecek et al. 2011). The original CRISPOR MIT and CFD scores were not recalculated and are not presented as scores for the alternate sequence.

The intended targets were checked separately in chromosome 12 data using a Jupyter Notebook in VS Code. The input was ALL.chr12.shapeit2_integrated_snvindels_v2a_27022019.GRCh38.phased.vcf from the IGSR 20190312_biallelic_SNV_and_INDEL release. Its header identifies GRCh38. The notebook read the full file and retained records overlapping the two 23-base target-plus-PAM regions: chr12:112978698–112978720 for 200forw and chr12:112978746–112978768 for 248forw. Coordinates are 1-based and inclusive, and both sequences are on the forward strand.

The Task 2 target sequences were checked against the saved Ensembl GRCh38 first-exon sequence. For each overlapping record, the VCF REF allele was checked against this reference. SNP alleles were then applied to each chromosome copy using the seven individuals’ genotypes. The notebook counted 20-base protospacer mismatches and checked the PAM separately. The code flags missing calls, alternate indels and uncertain phase for review. The saved results record that sequence coverage was not checked.

Data provenance and scope. The original chromosome 1/2 overlap analysis and the new chromosome 12 target check were performed in Python. This R chapter uses the original carrier CSV and sequence/genotype snapshot, together with the new chromosome 12 exports, to regenerate the tables. It recalculates sequence differences and genotype interpretation, but does not rerun either raw VCF scan during rendering. The chromosome 12 notebook records its reference checks, input header, results and actual software versions. The Reproducibility chapter explains how to repeat that scan. For the original chromosome 1/2 scan, agreement between assemblies, coordinates, strand and REF alleles must still be checked from its raw inputs.

4.3 Findings

Guide Availability in Individual Genomes

The chromosome 12 check found no overlapping VCF record for 200forw and four overlapping records for 248forw. At all four 248forw sites, every selected individual has the reference genotype 0|0. Therefore, none of the seven individuals carries a called alternate allele at these sites. The four records describe sites that vary in the wider dataset, rather than four changes in the selected individuals.

Both reconstructed copies match the corresponding 20-base guide sequence and retain TGG in all seven individuals: zero protospacer mismatches and two matching copies per person in the supplied calls (Table 4.1). The result is the same for HG00142, HG00178, HG00237, HG01521, HG03129, NA19175 and NA19462.

chr12 <- read_task3("Task3_chr12_on_target_summary.csv")

  "200forw" = "TCAGACACTGATCGACGAGATGG",
  "248forw" = "GGAACCCGAACAGTTCCCCCTGG")
stopifnot(nrow(chr12) == length(selected_guides) * length(samples),
          setequal(chr12$Guide, selected_guides),
          setequal(chr12$Sample, samples),
          !anyDuplicated(chr12[c("Guide", "Sample")]),
          all(chr12$End - chr12$Start == 22L))
for (copy in 1:2) {
  sequences <- chr12[[paste0("Copy_", copy, "_sequence")]]
  recalculated <- vapply(seq_len(nrow(chr12)), function(i)
    mm20(chr12_reference[[chr12$Guide[i]]], sequences[i]), integer(1))
  stopifnot(all(recalculated == chr12[[paste0("Mismatches_", copy)]]),
            all(vapply(sequences, pam, character(1)) ==
                chr12[[paste0("PAM_", copy)]]))
}
chr12_gt <- t(vapply(chr12_variants$GT, split_gt, integer(2)))
stopifnot(!anyNA(chr12_gt))
chr12_alt <- rowSums(chr12_gt > 0L) > 0L
chr12_sites <- unique(chr12_variants[c("Guide", "Chromosome", "POS", "REF", "ALT")])
chr12_table <- do.call(rbind, lapply(selected_guides, function(g) {
  x <- chr12[chr12$Guide == g, ]
  n_records <- sum(chr12_sites$Guide == g)
  stopifnot(all(x$Overlapping_records == n_records))
  carriers <- unique(chr12_variants$Sample[chr12_variants$Guide == g & chr12_alt])
  copies <- unique(x$Matching_copies_in_called_data)
  data.frame(Guide = g,
    `GRCh38 target + PAM` = paste0("chr12:", x$Start[1], "-", x$End[1]),
    `Overlapping records` = n_records,
    `ALT carriers` = paste0(length(carriers), "/", length(samples)),
    `Matching copies per person` = paste(sort(copies), collapse = ", "),
    check.names = FALSE)
}))

Variants Affecting Predicted Off-Target Sites

Comparison of predicted off-target coordinates with the chromosome 1 and chromosome 2 VCF datasets identified a single variant overlapping a predicted off-target site associated with guide 248forw (Table 4.3). The variant was a G to A substitution at chromosome 1 position 224,887,199. It was present in 4 individuals (HG00142, HG03129, NA19175 and NA19462), while the remaining 3 individuals carried the reference genotype at this position. No overlapping variants were reported for guide 200forw within the reference-predicted sites assessed on chromosomes 1 and 2.

Effect on Off-Target Binding Risk

The G to A substitution changes the PAM of the reported off-target sequence from AGG to AGA (Table 4.5). It does not change the 20-base protospacer: its mismatch count remains 4 before and 4 after the variant. Comparing all 23 bases would mix protospacer mismatches with PAM differences and would not be comparable with the original CRISPOR mismatch count.

Show analysis code 
sequence_table <- data.frame(
  Sequence = c("Guide target", "Reference off-target", "Alternate off-target"),
  `20-base protospacer` = c(substr(site$GuideSeq, 1, 20),
                            substr(site$OriginalOfftarget, 1, 20),
                            substr(site$ModifiedOfftarget, 1, 20)),
  PAM = c(pam(site$GuideSeq), reference_pam, alternate_pam),
  `Protospacer mismatches` = c(0L, reference_mm, alternate_mm),
  check.names = FALSE)
knitr::kable(sequence_table)

The alternate allele removes the canonical NGG PAM. Under the NGG-based framework used for guide selection, this makes the alternate sequence a less suitable off-target candidate. This is a qualitative prediction; it does not establish zero binding or a measured reduction in activity. Noncanonical PAMs can sometimes support Cas9 activity (Haeussler et al. 2016).

Individual-level analysis showed different effects depending on genotype (Table 4.6). 3 individuals are heterozygous: one haplotype has the altered AGA PAM, while the other retains the reference AGG PAM. NA19462 is homozygous for the alternate allele, so both haplotypes have the altered PAM. Consequently, all four carriers should not be assigned the same whole-individual reduction in risk. Allele copy counts do not imply a proportional change in binding.

4.4 Discussion

The SNP changes one predicted 248forw off-target PAM while leaving the protospacer at four mismatches. For HG00142, HG03129 and NA19175, only one haplotype has the changed PAM; the other retains AGG. For NA19462, both haplotypes have AGA. HG00178, HG00237 and HG01521 retain AGG on both copies. This refines Task 2 by giving a genotype-specific interpretation of one reference-predicted site, rather than assigning the same change to all seven individuals. Human variants can create or remove PAMs and change recognition at intended and unintended sites (Lessard et al. 2017).

The evidence supports keeping both guides as candidates for further assessment. The chromosome 12 check found no called target or PAM change for either guide in any of the seven individuals. No overlapping variant was reported for 200forw in the chromosome 1/2 off-target subset. For 248forw, the SNP does not improve the protospacer match and removes the canonical PAM on ALT haplotypes. This does not establish that either guide is safer overall. Other predicted sites were not assessed, and variants may create sites absent from the reference-based list. Reconstructing individual haplotypes and repeating the search, or using a variant-aware tool, would address that question. Reliable sequence coverage across the chromosome 12 targets is still needed before confirming complete guide availability.

This project uses CRISPRi, which regulates transcription using nuclease-deactivated Cas9 rather than cutting DNA (Jensen et al. 2021). Therefore, these results concern potential off-target recognition and unintended gene regulation. CRISPOR cleavage-based scores do not directly measure CRISPRi repression. Experimental validation would be needed to confirm the functional effect of the PAM change.

4.5 Conclusion

Analysis of the supplied results identified one SNP overlapping a reference-predicted off-target site for guide 248forw in four of seven individuals. The variant changes the PAM from AGG to AGA while leaving the protospacer mismatch count at four. Three carriers are heterozygous and retain one reference haplotype; NA19462 is homozygous for the alternate allele. No overlapping variant was reported for guide 200forw in the chromosome 1/2 subset. The chromosome 12 check found no target or PAM change in the supplied calls for either guide in any of the seven individuals. Complete guide availability remains conditional because sequence coverage was not checked. The findings support individual genotype checks, while a wider analysis is needed to assess guide suitability.

samples <- c("HG00142", "HG00178", "HG00237", "HG01521",

# Original carrier export. Its Risk labels are not used in the corrected report.
hits <- read_task3("Task3_variant_hits.csv")
# Exact sequence pair and all seven genotypes transcribed from Task3.html.
site <- read_task3("Task3_site_snapshot.csv")
stopifnot(nrow(site) == 1L, all(samples %in% names(site)),
          all(hits$Guide %in% selected_guides),

split_gt <- function(gt) {
  alleles <- strsplit(gt, "[|/]")[[1L]]
  if (length(alleles) != 2L || any(!grepl("^[0-9]+$", alleles))) {
    return(c(NA_integer_, NA_integer_))
  }
  as.integer(alleles)
}
mm20 <- function(guide, target) {
  stopifnot(nchar(guide) == 23L, nchar(target) == 23L,
            grepl("^[ACGT]+$", guide), grepl("^[ACGT]+$", target))
  sum(strsplit(substr(guide, 1L, 20L), "")[[1L]] !=
      strsplit(substr(target, 1L, 20L), "")[[1L]])
}
pam <- function(sequence) substr(sequence, 21L, 23L)
reference_mm <- mm20(site$GuideSeq, site$OriginalOfftarget)
alternate_mm <- mm20(site$GuideSeq, site$ModifiedOfftarget)
reference_pam <- pam(site$OriginalOfftarget)
alternate_pam <- pam(site$ModifiedOfftarget)
stopifnot(reference_mm == site$OriginalMismatch,
          reference_mm == 4L, alternate_mm == 4L,
          reference_pam == "AGG", alternate_pam == "AGA",
          substr(site$OriginalOfftarget, 1L, 20L) ==
            substr(site$ModifiedOfftarget, 1L, 20L))

individual <- data.frame(Individual = samples,
  Genotype = vapply(samples, function(s) site[[s]][1L], character(1)),
  stringsAsFactors = FALSE)
gt <- t(vapply(individual$Genotype, split_gt, integer(2)))
stopifnot(!anyNA(gt), all(gt %in% c(0L, 1L)))
individual$`Reference PAM copies` <- rowSums(gt == 0L)
individual$`Alternate PAM copies` <- rowSums(gt == 1L)
individual$`PAMs on the two haplotypes` <- vapply(seq_len(nrow(gt)),
  function(i) paste(ifelse(gt[i, ] == 0L, reference_pam, alternate_pam),
                   collapse = " / "), character(1))
carrier_samples <- individual$Individual[individual$`Alternate PAM copies` > 0L]
stopifnot(setequal(carrier_samples, hits$Sample),
          all(hits$Genotype == individual$Genotype[match(hits$Sample, samples)]),
          all(hits$Position == site$Position), all(hits$REF == site$REF),
          all(hits$ALT == site$ALT), all(hits$Chromosome == site$Chromosome))

unique_hits <- unique(hits[c("Guide", "Chromosome", "Position", "REF", "ALT")])
guide_summary <- data.frame(Guide = selected_guides,
  `Unique overlapping variants` = vapply(selected_guides,
    function(g) sum(unique_hits$Guide == g), integer(1)),
  `ALT carriers (out of 7)` = vapply(selected_guides,
    function(g) length(unique(hits$Sample[hits$Guide == g])), integer(1)),
  check.names = FALSE)
number_carriers <- length(carrier_samples)
number_heterozygous <- sum(individual$`Alternate PAM copies` == 1L)
number_homozygous_alt <- sum(individual$`Alternate PAM copies` == 2L)
number_reference <- sum(individual$`Alternate PAM copies` == 0L)

### Effect on Off-Target Binding Risk

The G to A substitution changes the PAM of the reported off-target sequence from **AGG to AGA** (@tbl-task3-sequences). It does **not** change the 20-base protospacer: its mismatch count remains **`r reference_mm` before and `r alternate_mm` after the variant**. Comparing all 23 bases would mix protospacer mismatches with PAM differences and would not be comparable with the original CRISPOR mismatch count.

The alternate allele removes the canonical NGG PAM. Under the NGG-based framework used for guide selection, this makes the alternate sequence a less suitable off-target candidate. This is a qualitative prediction; it does not establish zero binding or a measured reduction in activity. Noncanonical PAMs can sometimes support Cas9 activity [@haeussler2016].

Individual-level analysis showed different effects depending on genotype (@tbl-task3-individuals). **`r number_heterozygous` individuals are heterozygous**: one haplotype has the altered AGA PAM, while the other retains the reference AGG PAM. **NA19462 is homozygous for the alternate allele**, so both haplotypes have the altered PAM. Consequently, all four carriers should not be assigned the same whole-individual reduction in risk. Allele copy counts do not imply a proportional change in binding.

## Discussion

The SNP changes one predicted 248forw off-target PAM while leaving the protospacer at four mismatches. For HG00142, HG03129 and NA19175, only one haplotype has the changed PAM; the other retains AGG. For NA19462, both haplotypes have AGA. HG00178, HG00237 and HG01521 retain AGG on both copies. This refines Task 2 by giving a genotype-specific interpretation of one reference-predicted site, rather than assigning the same change to all seven individuals. Human variants can create or remove PAMs and change recognition at intended and unintended sites [@lessard2017].

The evidence supports keeping both guides as candidates for further assessment. The chromosome 12 check found no called target or PAM change for either guide in any of the seven individuals. No overlapping variant was reported for 200forw in the chromosome 1/2 off-target subset. For 248forw, the SNP does not improve the protospacer match and removes the canonical PAM on ALT haplotypes. This does not establish that either guide is safer overall. Other predicted sites were not assessed, and variants may create sites absent from the reference-based list. Reconstructing individual haplotypes and repeating the search, or using a variant-aware tool, would address that question. Reliable sequence coverage across the chromosome 12 targets is still needed before confirming complete guide availability.

This project uses **CRISPRi**, which regulates transcription using nuclease-deactivated Cas9 rather than cutting DNA [@jensen2021]. Therefore, these results concern potential off-target recognition and unintended gene regulation. CRISPOR cleavage-based scores do not directly measure CRISPRi repression. Experimental validation would be needed to confirm the functional effect of the PAM change.

## Conclusion

Analysis of the supplied results identified one SNP overlapping a reference-predicted off-target site for guide 248forw in four of seven individuals. The variant changes the PAM from AGG to AGA while leaving the protospacer mismatch count at four. Three carriers are heterozygous and retain one reference haplotype; NA19462 is homozygous for the alternate allele. No overlapping variant was reported for guide 200forw in the chromosome 1/2 subset. The chromosome 12 check found no target or PAM change in the supplied calls for either guide in any of the seven individuals. Complete guide availability remains conditional because sequence coverage was not checked. The findings support individual genotype checks, while a wider analysis is needed to assess guide suitability.
