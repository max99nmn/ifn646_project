# Final Report — RStudio / Quarto

**Precision CRISPR Guide RNA Design for Differentially Expressed Genes in COVID-19**

This IFN646 group project links RNA-seq differential-expression analysis, CRISPRi guide selection for OAS2, and an assessment of individual genetic variation. The report is a Quarto book with executable R code in the task chapters and a shared bibliography.

The recorded environment uses:

|:----------|:---------------------------------------------|

RStudio is used to open the project and inspect the QMD files. Restoring the R dependencies may require internet access. Python is not required to render the current R chapters; the original Task 3 VCF analysis was performed separately in Python.

## Open the project and restore dependencies

1.  Obtain the project source files, data and figures, preserving their folder structure.
2.  Start a fresh RStudio session and open **Final Report.Rproj**.
3.  In the **R Console**, restore the dependencies and check their status:

``` r
renv::restore()
renv::status()
```

The recorded startup output reported the project as **out of sync** and noted that BiocManager was loaded before renv activated. Restart R before checking the environment. If inconsistencies remain, review the status output and reconcile the installed project packages with the lockfile. Confirm the environment before claiming a successful reproduction.

## Render the complete HTML book

Open a **Terminal** in the folder containing `_quarto.yml` and run:

``` bash
quarto render --to html
```

The project configuration enables code execution and disables caching and frozen results. Quarto renders the configured chapters in book order. Task 1 generates `data/consensus_table.rds` before Task 2 reads it.

Open **`_book/index.html`** to view the finished book.

For a preview while editing, run:

``` bash
quarto preview --to html
```

Rendering only `Task3.qmd` is useful for checking that chapter, but the complete report should be rendered from the project folder before submission.

## View the code in the HTML report

In a task chapter, click **Code** in the top-right corner:

-   **Show All Code** expands the available folded code blocks.
-   **Hide All Code** collapses those blocks.
-   **View Source** displays the complete QMD source, including hidden setup and calculation blocks.

Individual folded blocks can also be opened using **Show analysis code**. These controls display the code; they do not run it in the browser.

## Scope of Task 3 reproduction

The current Task 3 chapter reads the saved carrier CSV and site snapshot. It recalculates the 20-base protospacer mismatch counts, PAM differences and individual-genotype tables. The original `Risk` labels in the carrier CSV are not used for the revised interpretation.

The reported SNP changes the off-target PAM from **AGG to AGA** while leaving the protospacer at **four mismatches**. Three carriers retain one reference haplotype; NA19462 carries the alternate allele on both haplotypes. These are qualitative sequence-based findings, rather than measured changes in CRISPRi activity.

Rendering the R chapter does not repeat the original Python VCF scan or the external CRISPOR guide-design step. Repeating the VCF scan requires the original notebook code, both VCF files and the full CRISPOR export `offtargetsguide.txt`, with matching assembly, coordinate and strand information. The Python and package versions for that original step should be recorded separately from the R lockfile.

The intended OAS2 target sites on chromosome 12 have not been assessed with the chromosome 1/2 data. The existing off-target comparison also does not search for new sites created by variants outside the reference-predicted CRISPOR list. These limits are discussed in Task 3.
