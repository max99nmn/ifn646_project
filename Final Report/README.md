# Final Report — RStudio / Quarto

**Precision CRISPR Guide RNA Design for Differentially Expressed Genes in COVID-19**

This IFN646 group project links RNA-seq differential-expression analysis, CRISPRi guide selection for *OAS2*, and an assessment of individual genetic variation. The report is organised as a Quarto book with executable R code in the task chapters and a shared bibliography.

## Software environment

The recorded environment uses:

| Component | Recorded version |
| --- | --- |
| R | 4.5.1 (2025-06-13 ucrt), “Great Square Root”|
| Platform | Windows 11 x64, x86_64-w64-mingw32/x64|
| Quarto | 1.8.27|
| renv | 1.2.4|

The project package versions are recorded in `renv.lock`, including `DESeq2` 1.50.2, `edgeR` 4.8.2, `limma` 3.66.0, `tidyverse` 2.0.0, and `knitr` 1.52. Further session information is documented in `reproducibility.qmd`.

RStudio is used to open the project and inspect the QMD files. Restoring the R dependencies may require internet access. All data processing, statistical modelling, VCF parsing, sequence comparisons, and visualisations across Tasks 1, 2, and 3 are executed directly in R.

## Open the project and restore dependencies

1. Clone or download the project repository and retain its folder structure.


2. Open **Final Report.Rproj** in RStudio in a fresh R session.


3. Restore the recorded R package environment from `renv.lock` and check its status:



```r
renv::restore()
renv::status()

```

## Render the complete HTML book

Render the Quarto book to HTML via the RStudio **Render Book** button or by opening a **Terminal** in the `Final Report` directory containing `_quarto.yml` and running:

```bash
quarto render --to html

```

The three analytical stages execute in sequence during rendering:

1. **Task 1 (`Task1.qmd`):** Reads `data/gse159717_rnaseq_deseq_5dpi_counts_raw.tsv`, performs the differential expression analyses (`DESeq2` and `edgeR`), and exports the six consensus genes to `data/consensus_table.rds`.


2. **Task 2 (`Task2.qmd`):** Reads `data/consensus_table.rds`, justifies the selection of *OAS2*, extracts the canonical first-exon target region (`ENST00000392583.7`), and evaluates candidate CRISPRi guides (`200forw` and `248forw`) using CRISPOR predictions.


3. **Task 3 (`Task3.qmd`):** Reads `data/chr12_OAS2_7samples.vcf` to verify on-target guide and PAM conservation across the seven individuals (`HG00142`, `HG00178`, `HG00237`, `HG01521`, `HG03129`, `NA19175`, and `NA19462`) on chromosome 12 (filtering out population-only records where all seven samples are `0|0`), and screens `data/sampled_chr1.vcf.zip` and `data/sampled_chr2.vcf.zip` against the CRISPOR off-target intervals (`data/offtargetsguide.txt`) to evaluate haplotype-specific off-target binding risk in R.



For a live preview while editing, run:

```bash
quarto preview --to html

```

## View the code in the HTML report

In any task chapter, click **Code** in the top-right corner of the page:

* **Show All Code** expands all folded code blocks in the current chapter.


* **Hide All Code** collapses the code blocks to return to the main narrative and results.


* **View Source** opens the complete `.qmd` source for the chapter, including hidden setup chunks.



Individual code chunks can also be toggled using **Show analysis code**.
